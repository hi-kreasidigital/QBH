# Prototype Situs — Pasar Inklusif

Prototype one-page bilingual berbasis roadmap Komunitas UMKM Queer Jawa & Pasar Inklusif.

## Cara melihat
Buka `index.html` di browser. Tidak membutuhkan server untuk preview dasar.

## Yang sudah dimasukkan
- Hero dengan ilustrasi referensi yang diberikan.
- Struktur publik yang ringkas, bukan seluruh roadmap internal.
- ID/EN toggle.
- Latar belakang dan prinsip "produk yang bicara, bukan identitas".
- Pemisahan komunikasi eksternal/internal.
- Program komunitas.
- Safety/privacy principles.
- Roadmap publik 4 fase.
- Konsep Pasar Inklusif.
- CTA bergabung dan dukung.
- Placeholder link untuk formulir dan dukungan.

## Sebelum live
Ganti:
1. Nama resmi komunitas.
2. URL formulir pendaftaran.
3. Email/kontak aman.
4. Mekanisme donasi/QRIS/rekening setelah struktur pengelolaan dana disepakati.
5. Privacy policy final.
6. Copy bilingual final.
7. Hosting/domain dan analytics (jika dipakai), dengan mempertimbangkan privasi.

Prototype ini sengaja tidak menampilkan database anggota, SOP verifikasi, target internal, atau detail operasional roadmap.
